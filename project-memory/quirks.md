# Quirks

- App and planner commands are run from `source/`. Root launchers bootstrap or start the source app for supported platforms; manual setup also changes into `source/` before installing dependencies and starting Expo.
- Expo configuration uses the `gatorguide` scheme, portrait orientation, automatic light/dark behavior, static web output, typed routes, the React compiler, and the new architecture.
- Route metadata preserves hidden compatibility surfaces: the previous Home deep link points to Transfer Planner, the questionnaire has a `roadmap` alias, and legacy planner surfaces return to the current Transfer Planner tab. Settings is nested under Profile rather than being a primary tab.
- Planner artifacts marked generated by the source maintainer guide are outputs of planner scripts and should be regenerated through those scripts instead of hand-edited.
